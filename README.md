# AstrBot 指令大全插件

AstrBot 指令大全插件：一键查询所有已加载插件的指令、别名、权限与说明。数据来自 AstrBot 核心的指令注册表（自动包含指令组与子命令结构），支持自动分页与关键字搜索。

- 作者：云晓
- 版本：1.0.1
- 许可证：MIT（详见 LICENSE）

## 功能

### 查询全部指令（`/指令`）
- 发送 `/指令` 查看所有已加载插件的指令列表
- 按插件分组展示（插件显示名 + 插件包名）
- 每条指令展示：指令名、说明、权限标记（管理员 / 成员）、停用标记、别名
- 指令组自动展开子命令（缩进显示，如 `/game 卧底`）
- 指令总数统计（含子命令）与插件数统计

### 自动分页
- 内容超过单条消息长度上限（默认 2000 字符）时自动拆分为多页
- `/指令 <页码>`：翻到指定页（页码越界自动回退最后一页）
- 每页页头显示「第 X/Y 页」

### 关键字搜索
- `/指令 <关键词>`：只显示匹配的指令
- 匹配范围：插件名、插件显示名、指令名、别名、说明
- 顶层指令命中时显示整块（含子命令）；仅子命令命中时只显示该子命令
- `/指令 <关键词> <页码>`：搜索后翻页

## 配置项

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `page_chars` | 2000 | 每页最大字符数，超过自动分页 |
| `include_reserved` | true | 是否包含 AstrBot 内置指令（reserved），关闭后只显示第三方插件指令 |
| `show_disabled` | true | 是否显示已停用指令（带 `[停用]` 标记），关闭后直接隐藏 |
| `admin_only` | false | 仅管理员可查询（需同时配置 `admin_umos` 白名单） |
| `admin_umos` | 空 | 管理员会话白名单（如 `default:GroupMessage:1234567890`），多个用英文逗号分隔 |

## 说明

- 默认所有人可查询（适合群友自助查指令），如需限制请开启 `admin_only` 并配置 `admin_umos`
- 已停用指令（在 AstrBot 指令管理中关闭的）默认带 `[停用]` 标记展示，可配置隐藏
- 数据实时来自 AstrBot 指令注册表：插件启停、指令改名/改权限后查询结果自动同步，无需重启
